Notebooks

Tick a folder and Jotted reads it, along with every folder inside it. New writing becomes to-do items.

    What changes

    • One row per folder in a tree, instead of a card per folder. Forty-odd folders fit on one screen.
    • Subfolders sit under their parent. A ticked parent shows its children ticked in pencil, “via Mable”, because Jotted already reads them.
    • “Reading” chips at the top answer “what is Jotted reading?” without scrolling.
    • Search, and a “Being read” filter, for long libraries.
    • The folder’s documents sit beside the tree, so choosing a folder no longer scrolls them off screen.
    • “From now on / Everything” moves to the detail panel, with one line on what each means.

    What it relies on

    • watch covers a folder and everything under it (Settings.watches), and library counts include subfolders. The tree only shows what the CLI already does.
    • Ticking a parent runs watch add, then watch remove for any child that had its own tick, so settings.watch stays tidy. Undo puts them back.
    • A new tick starts as “From now on” (watch add then watch from-now), so old notebooks don’t flood the list. This one is a proposal.
    • Setup’s compact picker can reuse the tree without the preview.

    Open questions

    • Leaving one folder out of a ticked parent needs an exclude in the CLI (e.g. watch exclude PATH). Until then those rows can’t be unticked.
    • Should single documents be pickable in the preview? watch already takes a document path.
    • Hide the To-do document’s folder, or keep it with the “made by Jotted” note?
