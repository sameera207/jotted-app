# Jotted for desktop

Your reMarkable to-do list on your Mac: one sheet with printed checkboxes, the same rows as
the To-do document on the tablet, and your own ink where you wrote by hand.

The app wraps the [`jotted`](https://github.com/sameera207/jotted-cli) CLI, bundled inside
it. See `AGENTS.md` to work on it, `specs/Desktop-app-spec.md` for the plan and
`docs/bundling.md` for how the CLI is packaged.
